# MyApplication_EXP-7
Aim

To develop an Android application that demonstrates menu operations such as Cut, Copy, Paste, Delete, Select All, and Unselect All using EditText and Menu items.

Algorithm
1. Open Android Studio and create a new Android project.
2. Design the user interface using LinearLayout and EditText in XML.
3. Create a menu resource file containing menu items like Cut, Copy, Paste, Delete, Select All, and Unselect All.
4. Write Java code to display the menu using onCreateOptionsMenu().
5. Handle menu item selection using onOptionsItemSelected().
6. Implement Cut operation by storing text and clearing EditText.
7. Implement Copy and Paste operations using a temporary clipboard variable.
8. Implement Delete, Select All, and Unselect All functionalities.
9. Display Toast messages for each operation.
10. Run the application and test all menu options successfully.
